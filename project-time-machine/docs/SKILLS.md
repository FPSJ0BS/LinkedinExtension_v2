# Required Skill Set

Load only the capabilities relevant to the current task.

## Project analysis
- Repository structure recognition
- Existing architecture and convention identification
- Scope and dependency impact analysis

## Frontend
- Component architecture
- Responsive layout and styling
- State and form management
- Routing and client-side data flow
- Accessibility and browser compatibility
- Performance and animation optimisation

## Backend and API
- API design and validation
- Authentication and authorization concepts
- Error handling and logging
- File upload and data-processing safety
- Service and middleware architecture

## Database
- Schema design and migrations
- Constraints, indexes, and relationships
- Query correctness and transaction safety
- Data integrity and rollback awareness

## Testing and debugging
- Unit, integration, and end-to-end testing
- Build, lint, type-check, and runtime diagnosis
- Dependency and configuration troubleshooting
- Regression and edge-case analysis

## Security
- Secret handling
- Input validation and output encoding
- Access-control verification
- Dependency vulnerability awareness
- Safe filesystem and command execution

## Version control
- Clean task boundaries
- Git status, diff, commit, tag, revert, reset, reflog, and conflict handling
- Safe backup and recovery
- Preservation of unrelated changes

## Documentation
- Accurate task summaries
- Clear changed-file and test records
- No invented results or unsupported claims
